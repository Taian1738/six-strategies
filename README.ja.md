# 六韜（LT）

[中文](./README.md) · [English](./README.en.md) · [한국어](./README.ko.md) · [Español](./README.es.md) · [Français](./README.fr.md)

六韜は、Codex 向けのソフトウェアエンジニアリング協働プロトコルです。複雑な開発、修正、リファクタリング、長期保守を、追跡可能で検証可能な実行サイクルに整理します。

## 特徴

- `R-`：要求と受け入れ条件を記録します。
- `A-`：アーキテクチャ、境界、不変条件、重要な判断を記録します。
- `F-`：ファイル所有権が明確な実装バッチに分割します。
- `T-`：テスト、コマンド、検証可能な証拠を固定します。
- 基盤アーキテクチャ、公開契約、権限、移行、IPC、プラグイン、ビルド、リリースには専用ゲートを適用します。

## ワークフロー

```text
目標の確定 → 影響範囲の判断 → 最小アーキテクチャ
    → 実装 → 即時検証 → プロジェクト記憶 → 監査 → 変更ログ
```

SOL は未確定の重要な設計、公開契約、不可分な実装、最終監査を担当します。Luna は、決定済みで範囲が限定された事実収集、実装、検証、機械的なログ作成を担当します。

## インストール

[Release から ZIP をダウンロード](https://github.com/Taian1738/six-strategies/releases/download/v2026.08.21/ltskill-20260821-142646.zip)し、`<CODEX_HOME>/skills/ltskill/` に解凍してください。ディレクトリ構造を維持した後、`$ltskill` で明示的に呼び出せます。
