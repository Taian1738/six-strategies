# 六韬（LT）

六韬是一套面向软件构建、修复、重构与长期维护的低上下文协作协议。它把需求、架构决策、实现批次、验证证据和变更日志串成可追溯闭环，并通过 SOL/Luna 分层协作控制成本与风险。

## 核心能力

- 以 `R- → A- → F- → T-` 建立需求、架构、实现和验证追踪。
- 通过 Luna 事实取证门与能力门，限制上下文范围、写入范围和未决语义。
- 将关键架构、跨模块契约、持久化、IPC、权限、插件、构建与发布底座纳入专门门禁。
- 对普通任务执行最小充分验证；对触发条件的变更执行统一全维审计。
- 维护精简项目索引和集成级变更日志，方便后续按功能增量修改。

## 包内容

`ltskill-20260821-142646.zip` 是可导入的完整技能包，包含：

- `SKILL.md`：六韬主协议，当前协议版本 `LT-2026-08-21.11`
- `agents/openai.yaml`：代理配置
- `references/`：调度契约、成本控制、审计路由、底层架构门、项目记忆和变更日志规范

## 安装

将压缩包解压到 Codex 技能目录，并保持目录结构：

```text
<CODEX_HOME>/skills/ltskill/
├── SKILL.md
├── agents/openai.yaml
└── references/
```

安装后可使用 `$ltskill` 显式调用六韬。

## 使用边界

六韬默认采用 Ponytail 的最小实现原则：优先复用现有实现、标准库和已安装能力。它不会为普通单功能开发自动扩大为底层架构重构，也不会在没有明确授权时执行发布、安装依赖或真实环境变更。
