# 六韬（LT）

[中文](./README.md) · [English](./README.en.md) · [日本語](./README.ja.md) · [Español](./README.es.md) · [Français](./README.fr.md)

六韬는 Codex를 위한 소프트웨어 엔지니어링 협업 프로토콜입니다. 복잡한 개발, 수정, 리팩터링 및 장기 유지보수 작업을 추적 가능하고 검증 가능한 실행 흐름으로 정리합니다.

## 핵심 기능

- `R-`: 요구사항과 수용 기준을 기록합니다.
- `A-`: 아키텍처, 경계, 불변조건 및 핵심 결정을 기록합니다.
- `F-`: 파일 소유권이 명확한 구현 배치로 작업을 나눕니다.
- `T-`: 테스트, 명령어 및 검토 가능한 증거를 고정합니다.
- 기반 아키텍처, 공개 계약, 권한, 마이그레이션, IPC, 플러그인, 빌드 및 릴리스에는 전용 게이트를 적용합니다.

## 작업 흐름

```text
목표 확정 → 영향 범위 판단 → 최소 아키텍처
    → 구현 → 즉시 검증 → 프로젝트 기억 → 감사 → 변경 로그
```

SOL은 결정되지 않은 핵심 설계, 공개 계약, 분리할 수 없는 핵심 구현 및 최종 감사를 담당합니다. Luna는 결정이 끝나고 범위가 제한된 사실 수집, 구현, 검증 및 기계적인 로그 작성을 담당합니다.
